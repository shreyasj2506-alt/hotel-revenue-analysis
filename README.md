# Hotel Revenue Analysis Dashboard

## Project Overview
This project analyzes hotel booking data to understand revenue performance, room type performance, and booking status. I used MySQL to perform data analysis and Microsoft Excel to create a dashboard with charts, key performance indicators (KPIs), and business insights.

## Objectives
- Calculate total revenue from completed bookings.
- Compare revenue across different room types.
- Analyze monthly revenue trends.
- Compare revenue across cities.
- Understand booking status distribution.
- Present findings through an Excel dashboard.

## Tools Used
- **MySQL** — Data storage, SQL queries, and analysis.
- **Microsoft Excel** — Data tables, charts, KPI cards, and dashboard creation.
- **GitHub** — Project documentation and portfolio hosting.

## Dataset
The project uses a fictional dataset containing 12 hotel bookings.

The dataset includes:
- Booking ID
- Customer name
- City
- Room type
- Check-in date
- Check-out date
- Booking amount
- Booking status

## Key Findings
- **Total completed revenue:** ₹61,000
- **Completed bookings:** 10
- **Top-performing room type:** Deluxe, generating ₹30,000
- **Highest-revenue month:** March, generating ₹24,000
- **Highest-revenue city:** Pune, generating ₹22,000
- **Booking statuses:** 10 checked out, 1 checked in, and 1 cancelled

Revenue calculations include only bookings marked "Checked Out".

## Dashboard Features
The Excel dashboard contains:
1. Monthly Revenue Analysis
2. Revenue by Room Type
3. Revenue by City
4. Booking Status Distribution
5. KPI Cards
6. Business Insights

## Project Structure
- `hotel_analysis.sql` — SQL queries used for analysis.
- `Hotel_Revenue_Analysis.xlsx` — Excel workbook containing the data and dashboard.
- `screenshots/` — Screenshots of the completed dashboard.

## Conclusion
This project helped me practice SQL aggregation, grouping, filtering, and data analysis, along with Excel chart creation and dashboard design. It demonstrates how raw booking data can be converted into useful business insights.

## Note
This is a beginner portfolio project using fictional hotel booking data. The findings are illustrative and do not represent a real hotel's performance.
